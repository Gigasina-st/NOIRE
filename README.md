# NOIRÉ

Premium editorial fashion e-commerce homepage built with React, TypeScript, Vite and Tailwind CSS.

## Run locally
npm install
npm run dev

## Build
npm run build

The current phase is intentionally frontend-only: no authentication, checkout or backend. Product content lives in `src/data.ts`, while the page is composed from reusable sections in `src/App.tsx`.

Photography uses remote Unsplash images; replace these URLs with licensed brand photography before production.
